# 📊 Análise de Vendas com SQL e Power BI

## 📌 Sobre o projeto
Este projeto tem como objetivo analisar dados de vendas e gerar insights através de consultas em SQL e visualizações no Power BI.

A proposta é simular um cenário real de análise de dados, desde a organização da base até a construção de um dashboard interativo.

---

## 🛠️ Ferramentas utilizadas
- Excel (criação e organização da base de dados)
- SQL (análise e manipulação dos dados)
- Power BI (criação de dashboard e visualizações)

---

## 📊 Análises realizadas
- Faturamento total
- Total de vendas
- Quantidade de produtos vendidos
- Faturamento por produto
- Faturamento por categoria
- Faturamento por cidade
- Análise temporal (por mês)
